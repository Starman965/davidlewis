Cackie

Simple iPad Word Processor

About Cackie

Cackie is a minimal, easy-to-use word processor designed specifically for iPad users who want a clean, distraction-free writing experience. Built with accessibility in mind, featuring large, easy-to-tap buttons and an intuitive two-row ribbon interface.

💾

Auto-Save

Documents automatically save as you type. Never lose your work with auto-save functionality that happens every 2 seconds.

✨

Rich Text Formatting

Bold, italic, underline, font sizes from 12pt to 72pt, and text alignment options for beautiful documents.

☁️

iCloud Drive Integration

Seamlessly save and open documents from iCloud Drive, local storage, or external drives through the Files app.

📄

RTF Format

Preserves all formatting (bold, italic, font size, alignment) in industry-standard RTF format.

🖨️

Print Support

One-tap printing with iOS print dialog for easy document output.

↩️

Undo/Redo

Full undo and redo support with convenient toolbar buttons.

📋

Clipboard Operations

Cut, copy, and paste with smart button states that disable when unavailable.

♿

Accessibility First

Large, easy-to-tap buttons perfect for users of all abilities. Built-in spell check and autocorrect.

Key Features

Two-Row Ribbon

Organized toolbar with file operations on top, formatting below

Document Management

Open, Save, Save As, and New Document with confirmation

Smart Interface

Shows document name at top, ? button for help anytime

Memory

Automatically remembers and opens your last document

Perfect For

  1. Simple Writing

    No complicated menus or overwhelming features. Just write.

  2. Large Text Editing

    Default 20pt text with comfortable reading padding makes documents easy to read and edit.

  3. Easy File Management

    Save anywhere with full Files app integration. Access your documents on all devices via iCloud.

  4. Forgiving Experience

    Auto-save means you never have to remember to save. Spell check catches mistakes automatically.

Built With Love

Cackie was created by David Lewis especially for his mom, Carol Lewis, who wanted a simple, comfortable writing experience on iPad. Every feature was designed to be easy to understand and forgiving to use.
