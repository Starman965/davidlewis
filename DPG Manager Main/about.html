DPG Manager

Danville Poker Group Management System

About DPG Manager

A modern, responsive website for managing the Danville Poker Group with both public and admin features. Built to streamline event management, RSVP tracking, and group communication for regular poker nights.

📅

Event Management

Create, edit, and manage poker events with dates, hosts, locations, and detailed information.

✋

RSVP System

Easy RSVP submission for upcoming events with real-time count tracking visible to all members.

👥

Member Management

Comprehensive member directory with contact information, photos, and hosting history.

📊

Attendance Reports

View detailed statistics on attendance patterns and hosting history for all group members.

📸

Photo Gallery

Upload and browse photos from past events with Firebase Storage integration.

🗳️

Polling System

Create and manage group polls for decisions and preferences with real-time vote tracking.

🔐

Admin Access

Secure admin login with email/password authentication for authorized users only.

📱

Responsive Design

Mobile-first approach with collapsible navigation works perfectly on all devices.

Technical Architecture

Frontend

HTML5, CSS3, Vanilla JavaScript

Backend

Firebase (Realtime Database, Auth, Storage)

Design

Card-based UI with dark theme navigation

Hosting

GitHub Pages with custom domain

Public Features

  1. Home Dashboard

    Welcome page with quick links to all major sections and upcoming event information.

  2. Events Calendar

    View all upcoming poker events with complete details including host, location, date, and time.

  3. Easy RSVP

    Simple form to submit your attendance response for upcoming events.

  4. Statistical Reports

    Browse attendance statistics and hosting history to see group participation patterns.

  5. Photo Gallery

    Relive memories by browsing photos from past poker nights and events.

Admin Features

Authorized administrators have access to powerful management tools for running the group effectively.

Event Control

Full CRUD operations for poker events

Member Directory

Add, edit, and manage member information

Poll Management

Create and manage group polls and surveys

Photo Upload

Upload and organize event photos to gallery

Private Group Application

DPG Manager is a private application built for the Danville Poker Group. While public features are accessible to all members, administrative functions require secure authentication. The system is optimized for the group's specific needs and workflow.
